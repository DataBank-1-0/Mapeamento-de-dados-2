Documentação Técnica do Projeto PixelBlox

1. Introdução

O PixelBlox é um jogo extremamente simples, inspirado em Minecraft, desenvolvido no Roblox Studio. Este documento reúne a documentação completa do projeto, contendo informações do modelo de dados, diagramas, scripts SQL e demais aspectos técnicos essenciais para o desenvolvimento e manutenção do sistema.

2. Modelo Conceitual

O modelo conceitual representa as principais entidades e seus relacionamentos no contexto do jogo PixelBlox:

  • Jogadores: Informações dos usuários, como nome, email, senha e data de cadastro.
  • Itens: Blocos, ferramentas e outros objetos que os jogadores podem utilizar.
  • Mundos: Espaços persistentes onde os jogadores constroem e interagem.
  • Transações: Registros de compras, trocas e demais interações envolvendo os itens.

7. Documentação de Mapeamento

O mapeamento entre o sistema (jogo PixelBlox) e o banco de dados é realizado de forma direta. As tabelas Jogadores, Itens, Mundos e Transacoes recebem os dados provenientes das ações dos usuários e das transações do jogo, garantindo consistência e integridade das informações.

8. Scripts SQL

Os scripts SQL a seguir exemplificam a criação das principais tabelas do banco de dados:

        -- esse é a tabela que guarda as info do site
        CREATE TABLE IF NOT EXISTS Jogadores (
            id SERIAL PRIMARY KEY,
            nome VARCHAR(255) NOT NULL,
            email VARCHAR(255) UNIQUE NOT NULL,
            data_cadastro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        );
        
        -- esse aqui guarda as info do joguinho, só isso memo
        CREATE TABLE IF NOT EXISTS EstadoJogo (
            id SERIAL PRIMARY KEY,
            id_jogador INTEGER NOT NULL REFERENCES Jogadores(id) ON DELETE CASCADE,
            world_state JSONB,  -- guarda tudo e issae
            ultima_modificacao TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        );

9. Metadados

Metadados são informações sobre os dados armazenados. No contexto do PixelBlox, destacam-se:

  • Origem: Dados oriundos dos jogadores e das interações no jogo.
  • Qualidade: Restrições nos campos (NOT NULL, UNIQUE) garantem integridade e consistência.
  • Segurança: Senhas e dados sensíveis são armazenados de forma criptografada.

10. Políticas de Governança de Dados

As políticas adotadas visam garantir a segurança, privacidade e integridade dos dados:

  • Segurança: Criptografia de senhas e dados sensíveis, uso de chaves primárias e estrangeiras.
  • Privacidade: Dados pessoais dos jogadores não são compartilhados sem consentimento.
  • Integridade: Restrições e integridade referencial para evitar alterações indevidas.

11. Conclusão

Esta documentação unificada apresenta a estrutura técnica e os artefatos do projeto PixelBlox, abrangendo desde o modelo de dados até as políticas de governança. A organização dos elementos facilita a manutenção, a análise e o desenvolvimento contínuo do jogo.
